# Experiment Entrypoints

Use these top-level scripts as the canonical entrypoints:

- `a_local_fp32.sh`
- `b_local_fp32.sh`
- `a_to_b_local_fp32.sh`
- `b_to_a_local_fp32.sh`
- `a_to_b_new_only_local_fp32.sh`
- `b_to_a_new_only_local_fp32.sh`

The older `stage_*` scripts are retained as implementation details and
compatibility shims.
